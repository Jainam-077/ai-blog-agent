# AI Blog Writing Agent

An AI-powered multi-agent blog generation platform that creates SEO-friendly articles in minutes.

## Features

- Multi-Agent Blog Generation
- Blog History Management
- SEO Optimized Content
- Export Blog (PDF/DOCX)
- User Authentication
- Settings & Help Center
- Modern Responsive UI

## Architecture

Research Agent
↓
Outline Agent
↓
Writer Agent
↓
Editor Agent
↓
Final Blog

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python
- OpenAI API

## Installation

### Backend

pip install -r requirements.txt

uvicorn main:app --reload

### Frontend

npm install

npm run dev
